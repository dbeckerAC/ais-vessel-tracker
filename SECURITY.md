# Security

This repository is a local playground, not an internet-ready service. It has no authentication or authorization; keep it on a trusted machine or private network and do not expose port 8000 or Adminer to the public internet.

Keep API tokens in `.env`, never commit collected AIS data, and rotate a token immediately if it is disclosed. Report sensitive vulnerabilities through the repository's private GitHub Security Advisory feature once available; do not put secrets in a public issue.
